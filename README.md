## 📌 Sobre o Projeto

**O que é:**  
O **NeuroCore** é uma **plataforma base de inteligência artificial local, modular e open-source**, desenhada para servir de fundação para qualquer solução de IA que você queira construir.

**Para que serve (escopo de 10 anos):**  
Do assistente pessoal residencial, IDE inteligente, LLM próprio, agentes B2B para sites, chatbots para empresas e fábricas, geração de áudio, imagem e vídeo — até, no longo prazo, se tornar o **sistema embarcado (cérebro) de robôs humanóides físicos**.

**O que já funciona hoje (30/09/2026 — prova de conceito):**
Conversa em PT-BR · Geração e explicação de código · **Agente de Automação Windows (9 ações)** · **Leitura e Pesquisa de Arquivos com Whitelist de Segurança** — tudo 100% local, zero nuvem obrigatória.

### ▶️ Quickstart — Rodar a Prova de Conceito Localmente

**Passo 1 — Pré-requisitos (uma vez):**
Instale **Ollama**, **Python 3.12** e **Node.js 22** no Windows.

**Passo 2 — Baixar o núcleo:**
```bash
git clone https://github.com/Jhon-Ross/NeuroCore.git
cd NeuroCore
```

**Passo 3 — Instalar dependências:**
```powershell
# Backend Python
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# Frontend
cd frontend
npm install
cd ..

# Modelo padrão (fallback 100% compatível · ~4.3GB)
ollama pull llama3:latest
```

**Passo 4 — Ligar tudo:**
No PowerShell, execute:
```powershell
.\scripts\iniciar_prometeu.ps1
```

A interface abre automaticamente no seu navegador padrão: `http://localhost:3000`.
