## 🎯 Como usar este template

Sempre que for criar um diário novo:

1. **Copie** TODO o conteúdo deste arquivo (a partir da linha 27 abaixo: `--- INÍCIO DO TEMPLATE ---`)
2. **Cole** em um arquivo novo na pasta `docs/`
3. **Nomeie o arquivo seguindo estritamente esta convenção:**
   ```
   03 - Diario - YYYY-MM-DD - DIA N - NOME CURTO DO DIA.md
   ```
   Exemplos:
   - `03 - Diario - 2026-09-29 - Dia 1 - Prometeu Fala Por Texto.md`
   - `03 - Diario - 2026-09-30 - Dia 2 - Voz Ativada.md`
   - `03 - Diario - 2026-12-25 - Dia 90 - Natal com Prometeu Adulto.md`
